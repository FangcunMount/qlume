# Qlume 小程序首页设计

## 1. 设计结论

Qlume 小程序首页不应该照搬官网首页。

官网首页解决的是品牌认知、产品解释和信任建立；小程序首页解决的是用户进入之后立刻开始、继续任务、查看结果。

因此，小程序首页应定位为：

**任务首页 / 用户驾驶舱**

而不是：

**品牌首页 / 长文案介绍页**

## 2. 首页目标

首页只服务 4 件事：

1. 让用户知道当前正在使用哪个档案。
2. 让用户一眼看到此刻最该做的事情。
3. 让用户快速开始一次测评或继续未完成测评。
4. 让用户快速回到最近结果与记录。

不把首页做成量表目录页，也不把首页做成搜索页。

## 3. 首页原则

1. 先任务，后分类。
2. 先推荐，后检索。
3. 先用户状态，后通用内容。
4. 首页尽量少解释品牌，多推动下一步动作。
5. 量表分类用用户语言，不用专业术语堆砌。

## 4. 信息架构

### 4.1 顶部结构

- 导航栏标题：`Qlume 测评`
- 右侧可选入口：通知、帮助
- 不保留搜索框

### 4.2 首页区块顺序

1. 当前档案卡
2. 当前任务主卡
3. 今日推荐 / 为你推荐
4. 场景入口
5. 专业精选
6. 最近记录摘要

## 6. 模块设计

### 6.1 当前档案卡

作用：建立当前上下文。

建议字段：

- 姓名
- 性别 / 生日
- 档案标签，例如 `本人`、`孩子`、`学生`
- 最近测评时间
- 未完成任务数量

操作：

- `切换档案`
- `管理档案`

设计要求：

- 首页顶部必须固定有一张当前档案卡
- 卡片内容尽量简洁，不展开完整档案详情
- 如果没有档案，展示首个空状态 CTA：`创建档案`

### 6.2 当前任务主卡

这是首页最重要的一张卡，优先级高于分类。

优先顺序：

1. 有未完成测评时：展示 `继续上次测评`
2. 有机构任务但未开始时：展示 `开始任务`
3. 无任务但有推荐时：展示 `开始推荐测评`
4. 全部都没有时：展示 `扫码加入任务`

卡片内容建议：

- 任务名称
- 当前进度，例如 `已完成 12/20`
- 预计剩余时间
- 主按钮：`继续填写` / `立即开始`
- 次按钮：`扫码加入任务`

### 6.3 为你推荐

这一块取代搜索框，承担“发现下一步”的职责。

推荐来源可分三层：

1. 基于最近记录推荐
2. 基于当前档案年龄 / 身份推荐
3. 基于通用热门推荐

推荐卡片只保留高价值信息：

- 标题
- 一句话理由
- 时长
- 适用对象
- CTA：`立即开始`

文案示例：

- `最近你完成了睡眠记录，推荐继续做情绪状态短测评`
- `适合 3 分钟完成，用于日常状态自查`
- `适合家长填写，用于儿童发展观察`

### 6.4 场景入口

这块保留，但不叫“量表分类”，改成更用户友好的 `测评场景`。

推荐场景：

- 儿童发展
- 情绪状态
- 睡眠与压力
- 注意力与执行功能
- 感觉统合
- 家庭与学校反馈

原因：

- 这是用户语言，而不是专业术语目录
- 比 `多动 / 抽动 / 自闭` 更容易理解
- 更适合首页入口，不会显得过于专科化

交互：

- 点击进入发现页的对应筛选结果
- 首页只展示 6 个入口，不要继续往下滚一整屏分类

### 6.5 专业精选

这块保留内容流结构，用于承接更稳定的推荐内容。

建议来源：

- 热门测评
- 新手推荐
- 专业常用
- 机构精选

卡片字段：

- 名称
- 一句话简介
- 时长
- 适用对象

卡片示例：

`执行功能行为评定量表（Brief-2）`

`适用于执行功能与行为状态观察，适合家长或教师填写。`

`约 3 分钟`

### 6.6 最近记录摘要

首页只展示摘要，不展示完整历史。

建议内容：

- 最近完成的 2 项测评
- 最近 1 条可查看结果
- `查看全部记录`

目的：

- 让用户知道“做完去哪看”
- 避免记录页和首页重复

## 7. TabBar 设计

建议保持 5 个入口：

- 首页
- 发现
- 扫码测评
- 记录
- 我的

职责分工：

- 首页：任务、推荐、继续动作
- 发现：分类、筛选、完整量表库
- 扫码测评：邀请码 / 二维码加入
- 记录：历史记录、结果、报告
- 我的：档案、设置、帮助

## 8. 状态流

### 8.1 首次进入

- 无档案
- 无历史
- 首页主卡显示：`创建档案`
- 推荐区显示：`新手推荐`

### 8.2 回访用户

- 有档案
- 有最近记录
- 首页主卡显示：`继续测评` 或 `查看结果`
- 推荐区显示：基于历史的个性化推荐

### 8.3 机构任务用户

- 通过二维码或邀请进入
- 首页主卡优先显示机构任务
- 次按钮显示：`扫码加入其他任务`

### 8.4 多档案用户

- 首页顶部卡片显示当前档案
- 明确提供 `切换档案`

## 9. 视觉方向

视觉上不做“官网缩小版”，但要继承 Qlume 的气质。

建议方向：

- 背景：浅灰白，干净留白
- 主色：Qlume 蓝绿渐变作为按钮和重点状态色
- 卡片：大圆角、轻阴影、白底
- 图标：线性图标，少量强调色
- 首页第一屏不堆很多模块，控制在 3 块核心卡片以内

避免：

- 大段品牌文案
- 大面积 banner
- 一上来就是 8 个以上分类格子
- 过重的搜索心智

## 10. 文案语气

首页文案应当：

- 简短
- 温和
- 可执行
- 避免诊断感

推荐用语：

- `继续填写`
- `立即开始`
- `为你推荐`
- `最近完成`
- `约 3 分钟`
- `适合家长填写`

避免用语：

- `诊断`
- `病情判断`
- `治疗建议`

## 11. 最终建议

### 首页做什么

- 当前档案
- 当前任务
- 推荐测评
- 场景入口
- 精选内容
- 最近记录摘要

### 首页不做什么

- 不做搜索
- 不做完整量表目录
- 不做官网式品牌长页
- 不做过多专业术语分类

### 一句话定义

**Qlume 小程序首页应该是一个“下一步行动页”，不是一个“量表目录页”。**
